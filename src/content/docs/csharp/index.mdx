## How this is asked

Expect 30–50% of a .NET technical round here. Interviewers go one level below syntax: *what does the compiler/runtime do?* Typical openers are value vs reference types, abstract class vs interface, IEnumerable vs IQueryable, async/await internals and GC generations.
